# InfoClub Presentation Agent

AI-powered presentation generation system for InfoClub.

## Purpose

- generate presentation structures
- generate slide content
- apply InfoClub brand guidelines
- support multiple presentation types

## Inputs

- audience
- presentation goal
- knowledge base context

## Outputs

- slide structure
- slide content
- branded presentation draft

## Architecture

Knowledge Layer
→ Prompt Layer
→ Presentation Generator
→ Presentation Artifact
