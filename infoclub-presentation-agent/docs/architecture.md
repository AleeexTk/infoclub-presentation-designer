# Architecture

## Goal

Generate InfoClub presentations from organizational knowledge.

## Pipeline

User Request
→ Audience Analysis
→ Knowledge Retrieval
→ Presentation Planning
→ Slide Generation
→ Brand Enforcement
→ Final Presentation Draft

## Knowledge Sources

- InfoClub description
- services
- events
- community information

## Presentation Types

- partner presentation
- investor presentation
- community presentation
- event presentation
