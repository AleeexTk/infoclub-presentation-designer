# Slide Content Rules

## Required Output Fields

- `title`
- `content`

## Content Rules

- Content must be a list of concise bullets.
- Each bullet must support the slide purpose.
- Each bullet must be appropriate for the requested audience, goal, tone, and language.
- Bullets must not include unsupported InfoClub facts.
- Unknown facts must be marked as verification required instead of being presented as true.

## Claim Rules

- Use `knowledge/claims_and_constraints.md` before adding factual statements.
- Do not invent metrics, mission statements, partner names, sponsor names, investor claims, services, events, or outcomes.
- If evidence is missing, use a verification bullet instead of a factual claim.

## Style Rules

- Prefer clear presentation language over long paragraphs.
- Keep slide content scannable.
- Avoid final visual layout decisions; those belong to brand enforcement and rendering.
