# Slide Content Generator Examples

## Input

```yaml
slide:
  title: Community Mission
```

## Output

```yaml
title: Mission of InfoClub
content:
  - State the verified InfoClub mission, or mark the mission as verification required.
  - Explain why the mission matters to the selected audience.
  - Connect the mission to the presentation goal without adding unsupported facts.
```

## Notes

- The example uses a verification-safe bullet because the current knowledge layer marks the InfoClub mission as unknown.
- The generator may replace verification-safe bullets only when approved knowledge sources provide verified mission content.
